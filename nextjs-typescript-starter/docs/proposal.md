# 学英语单词 H5 应用 — 需求文档

> 项目代号：**danci-h5**
> 技术栈：Next.js 14 (App Router) + TypeScript + TailwindCSS + Supabase + Drizzle ORM
> 文档版本：v1.0 · 2026-09-30

---

## 1. 项目背景与目标

### 1.1 背景
本项目是 `danci` 仓库下的 H5 端（手机网页端）英语单词学习应用，与已有的后台管理系统（`danci-admin`）共享同一套 Supabase 数据库与 Drizzle ORM 数据层。单词数据由后台维护并导入，前端只负责学习交互。

### 1.2 目标
- 提供一个轻量、能在手机浏览器内流畅使用的单词学习 H5。
- 区分「游客」与「登录用户」两种身份：游客可浏览单词书；登录用户可追踪学习进度。
- 复用已有 `app/login/page.tsx` 和 `app/register/page.tsx` 的鉴权逻辑，登录态与学习记录打通。

### 1.3 非目标（Out of Scope）
- 本期不实现单词发音音频播放（数据中预留 `usspeech` / `ukspeech` 字段，后续接入）。
- 不实现背单词的间隔重复算法（SSRSpaced Repetition），仅记录「最近学习的单词」。
- 不做单词收藏、错题本、每日打卡等增值功能，留待 v2。

---

## 2. 用户角色与场景

| 角色 | 描述 | 关键能力 |
| --- | --- | --- |
| **游客（未登录）** | 打开 H5 默认状态 | 浏览单词书列表；点击任意单词书触发登录弹窗 |
| **登录用户** | 完成邮箱+密码登录或注册 | 浏览单词书；进入学习；保留「最近学习」进度；查看「我的」信息 |

---

## 3. 信息架构与路由

H5 应用挂在 `/` 根路由下，路径设计如下：

```
/                        首页（单词书列表 + 最近学习）
/study/[bookId]          学习页（单词卡片流）
/word/[bookId]/[wordId]  单词详情页
/me                      我的（个人中心）
/login                   登录页（保留已有逻辑）
/register                注册页（保留已有逻辑）
/protected               已有登录后的示例页（保持不动）
```

底部 Tab Bar 始终显示在 `/`、`/me` 两个路由上；`/study/*`、`/word/*`、`/login`、`/register` 不显示底部 Tab。

## 4. 数据模型（与 Drizzle Schema 对齐）

### 4.1 已有表（来自后台，本期只读）
- `books`：单词书主表。字段：`id`, `title`, `cover_url`, `description`, `word_count`, `created_at`。
- `words`：单词表，单词 JSON 内容存放在 `content` JSONB 字段。

### 4.2 本期新增表

#### 4.2.1 `user_book_progress`（用户学习进度）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | uuid, PK | 默认 `gen_random_uuid()` |
| `user_id` | uuid, FK → users.id | 级联删除 |
| `book_id` | uuid, FK → books.id | 级联删除 |
| `last_word_id` | uuid, FK → words.id | 最近学习的单词 |
| `last_studied_at` | timestamptz | 默认 `now()` |
| `learned_count` | int | 已学习单词数（本期先不写入，预留字段） |

> 唯一约束：`(user_id, book_id)`，保证同一用户同一本书只有一条进度记录。

#### 4.2.2 RLS（行级安全）
- `user_book_progress` 必须开启 RLS。
- 策略：仅允许 `auth.uid() = user_id` 的用户读取/更新自己的进度。

### 4.3 单词 JSON 结构（已有）
单词详情页所需 `content` 字段结构（参见 `danci-admin/temp/PEPXiaoXue6_1.json` 第 4–183 行）：

```text
content.word.wordHead              单词本体（如 "science"）
content.word.wordId                单词 ID（如 "PEPXiaoXue6_1_1"）
content.word.content.trans[0]      中英释义
content.word.content.usphone       美式音标
content.word.content.ukphone       英式音标
content.word.content.usspeech      美式发音文件名
content.word.content.ukspeech      英式发音文件名
content.word.content.sentence       例句列表（sContent / sCn）
content.word.content.phrase        短语列表（pContent / pCn）
content.word.content.syno          近义词（hwds / tran）
content.word.content.relWord       同根词（hwd / tran）
```

## 5. 功能详述

### 5.1 底部 Tab Bar
- 包含两个 Tab：**首页**（图标 + 文字）、**我的**（图标 + 文字）。
- 当前 Tab 高亮（accent 色 + 加粗）。
- 固定在屏幕底部，高度约 `56px`，安全区适配 `pb-[env(safe-area-inset-bottom)]`。
- 仅在 `/` 与 `/me` 渲染（通过根布局中的 `usePathname()` 判断）。

### 5.2 首页 `/`

#### 5.2.1 登录态判断
- 页面加载时调用 `auth.getUser()`：
  - 已登录 → 渲染 5.2.2 完整版。
  - 未登录 → 渲染 5.2.3 简化版。

#### 5.2.2 已登录：完整首页
页面结构自上而下：

1. **顶部 Greeting Bar**
   - 左：当前用户邮箱前缀（如 `Hello, alex`）。
   - 右：可省略，或放置设置入口（本期省略）。

2. **最近学习模块**（**仅当有数据时展示**）
   - 标题「最近学习」+ 副标题「继续上次的单词书」。
   - 单张横向卡片，展示：
     - 单词书封面缩略图（左侧 64×64 圆角）。
     - 单词书标题。
     - 「上次学到：第 N 个单词 · 共 M 个」进度文案。
     - 右侧主按钮「继续学习」。
   - 整卡可点击，跳转 `/study/[bookId]`。
   - **空数据时整块不渲染**（包括标题）。

3. **全部单词书模块**
   - 标题「全部单词书」。
   - 列表：每项一张卡片，纵向排列。
     - 左侧封面图（48×48 圆角）。
     - 中间：书名 + 描述（单行省略）。
     - 右侧：`> ` 箭头。
   - 点击 → `/study/[bookId]`。

#### 5.2.3 未登录：简化首页
- 不显示「最近学习」模块。
- 「全部单词书」模块照常渲染。
- **任一单词书被点击** → 跳转 `/me`（锚点或参数携带 `?login=1`），**并弹出登录弹窗**。

### 5.3 登录/注册弹窗（Popup）

#### 5.3.1 触发与位置
- 触发场景 1：未登录用户点击任意单词书。
- 触发场景 2：直接访问 `/me` 时（兜底）。
- 弹窗以 Modal 形式覆盖在 `/` 或 `/me` 之上，居中显示，半透明遮罩。

#### 5.3.2 弹窗内容
- 与现有 `app/login/page.tsx` / `app/register/page.tsx` 同样的表单：
  - **邮箱**输入框（type=email）。
  - **密码**输入框（type=password）。
  - **主按钮**：「登录」或「注册」（根据弹窗 Tab 切换）。
- 弹窗顶部 Tab 切换：「登录 / 注册」，默认登录。
- 底部次级文案：「还没有账号？去注册」/「已有账号？去登录」。
- 提交时调用与现有一致的 Server Action：
  - 登录 → `signIn('credentials', { email, password, redirectTo: '/' })`。
  - 注册 → 调用 `createUser(email, password)`，成功后自动 `signIn` 并关闭弹窗。

#### 5.3.3 关闭与跳转
- 登录成功 → 关闭弹窗，停留在原页面，刷新登录态数据。
- 注册成功 → 自动登录并关闭弹窗。
- 用户可点击遮罩或右上角 `×` 关闭弹窗（关闭后若来源于单词书点击，且仍未登录，停留在 `/me`）。

### 5.4 我的页 `/me`

#### 5.4.1 加载逻辑
- 未登录 → 直接渲染登录弹窗（同 5.3），不展示个人信息卡片。
- 已登录 → 渲染以下内容：

#### 5.4.2 信息结构
1. **个人信息卡**
   - 顶部圆形头像（默认首字母占位）+ 邮箱地址（主标题）。
   - 副标题：「已学习 N 本单词书」。

2. **学习进度列表**
   - 标题「学习进度」。
   - 列表项：单词书名 + 进度条 + 文字「已学 X / Y」+ 「继续学习」文字链。
   - 数据来源：`user_book_progress` JOIN `books`。
   - 若无任何进度，展示空状态：「还没有学习记录，去首页挑一本单词书开始吧」+ 「去看看」按钮 → 跳转 `/`。

3. **退出登录按钮**
   - 危险样式（红色边框 + 红色文字），底部独立区域。
   - 点击 → 二次确认弹窗 → 调用 `signOut()` → 跳转 `/`。

### 5.5 学习页 `/study/[bookId]`

#### 5.5.1 进入行为
- 从「最近学习」进入：定位到 `last_word_id`，从**它的下一个**单词开始。
- 从单词书列表进入：从第 1 个单词开始。
- 进入时 URL 带查询参数 `?from=last|start`，可读可不读，主要由 Server Component 查询 `progress` 表判断。

#### 5.5.2 单词卡片 UI（极简）
单张卡片居中显示，仅展示最少信息：

```
┌──────────────────────────────┐
│   第 3 / 20 个                │  ← 顶部进度文案
│                               │
│        science                │  ← 单词本体（最大字号）
│      /ˈsaɪəns/                │  ← 美式音标（次级字号）
│                               │
│        科学                    │  ← 中文释义（一个示例）
│                               │
│  [查看详情]      [下一个 ›]    │  ← 双按钮
└──────────────────────────────┘
```

- **仅展示一条中文释义**：`content.word.content.trans[0].tranCn`。
- **不展示**例句、短语、近义词、同根词等（这些只在详情页展示）。
- 「查看详情」→ `/word/[bookId]/[wordId]`。
- 「下一个」→ 切换到当前数组的下一项；到末尾时按钮变为「完成本课」，点击后：
  - 写回 `user_book_progress`（更新 `last_word_id` 与 `last_studied_at`）。
  - 弹出轻提示「已完成《书名》本课学习」，3 秒后自动消失。
  - 跳转回 `/`。

#### 5.5.3 切换交互
- 默认通过「下一个」按钮切换。
- 进阶体验（可选）：左滑切换下一个、右滑切换上一个。本期可不实现，先用按钮。

### 5.6 单词详情页 `/word/[bookId]/[wordId]`

#### 5.6.1 数据来源
- 根据 `wordId` 在 `words.content.word.wordId` 上匹配（因为主键可能与业务 wordId 不同，需通过 JSONB 路径查询或预拉取整本书后过滤）。
- 推荐做法：服务端查询时使用 `content->'word'->>'wordId' = ${wordId}` 条件。

#### 5.6.2 展示字段
按以下顺序渲染：

1. **词头区**：单词 + 美/英音标 + 发音入口（本期占位 `▶ US / ▶ UK`，点击预留 TODO）。
2. **释义**：`trans[]` 列表，每条展示 `tranCn` 与 `tranOther`。
3. **例句**：`sentence.sentences[]`，每条展示英文 + 中文对照。
4. **短语**：`phrase.phrases[]`，每条展示 `pContent` + `pCn`。
5. **近义词**：`syno.synos[]`，按 `pos` 分组，展示 `hwds[].w` 与 `tran`。
6. **同根词**：`relWord.rels[]`，按 `pos` 分组，展示 `hwd` 与 `tran`。

字段为空时整块不渲染（与首页空数据处理一致）。

## 7. 验收标准（Acceptance Criteria）

### 7.1 首页
- [ ] 未登录用户访问 `/`，只能看到「全部单词书」模块，「最近学习」不渲染。
- [ ] 未登录用户点击任意单词书 → 跳转 `/me` 并自动弹出登录弹窗。
- [ ] 已登录用户首次访问 `/`，只显示「全部单词书」（最近学习为空时不渲染）。
- [ ] 已登录用户有学习进度后，「最近学习」渲染一张卡片，文案与按钮均可点击。

### 7.2 登录弹窗
- [ ] 弹窗可在 `/` 与 `/me` 上触发，遮罩点击可关闭。
- [ ] 登录/注册 Tab 切换流畅，表单校验与现有页面一致。
- [ ] 注册成功后自动登录并关闭弹窗。

### 7.3 我的页

## 8. 技术要点与约束

1. **复用鉴权**：登录/注册 Server Action 直接迁移到弹窗组件中使用，不重复实现。
2. **进度查询**：服务端组件读取 `user_book_progress`，避免在客户端做权限判断。
3. **JSONB 查询**：单词详情通过 `content->'word'->>'wordId'` 过滤；如性能不足，可改为预加载整本书到内存再客户端过滤。
4. **移动端适配**：所有页面以移动端 375px 宽度为基准设计，桌面端居中显示并限制最大宽度 `max-w-md`。
5. **底部 Tab Bar**：放在根布局中通过 `usePathname()` 条件渲染。
6. **空状态**：严格遵循 skill 要求 —— 空数据整块不渲染，避免「暂无数据」占位。
